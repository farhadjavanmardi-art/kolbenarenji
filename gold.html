Which mode to use

Direct needs nothing but a key — the page talks to Anthropic itself. Use it while the page lives on your own machine.

Backend keeps the key on the server, so the page can be hosted publicly. It needs two secrets set on the Supabase project: ANTHROPIC_API_KEY and GOLD_ACCESS_CODE (optionally GOLD_MODEL). The function stays disabled until the access code is set.
